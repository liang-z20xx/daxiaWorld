# 🦐 大虾世界 (Daxia World) v-2.0.0

> **“逐光赴春约，弘毅勇超越。”——弘毅班远足口号**

这是一款由个人完全独立开发的 **C++ / EasyX 剧情互动游戏**。包含了 **173 种结局**、**多条叙事主线**，以及一段关于灵宝一高弘毅班的真实青春回忆。

## 📖 项目简介

《大虾世界》是一个基于 Windows 平台的图形化剧情游戏。你将扮演“虾片”，在**大虾帝国**与**弘毅班校园**之间穿梭，做出影响命运的抉择。

- **游戏体量：** 5888 行代码，55 张精心排版的素材图片。
- **核心玩法：** 分支剧情选择，解锁 173 种截然不同的结局。
- **隐藏内容：** 内置成就系统、彩蛋文章、以及根据剧情触发的特定 BGM。

## 🛠️ 技术栈

- **编程语言：** C++
- **图形框架：** EasyX 26.1.1
- **版本控制：** Git / GitHub

## 🚀 运行方式（直接游玩）

如果你只想体验游戏成品（推荐），请前往右侧栏的 **`Releases`** 页面，下载最新的 `.zip` 压缩包。

1. 解压压缩包。
2. 确保游戏目录下有 `res` 文件夹（包含图片和音乐）。
3. **双击运行 `大虾世界2.0.0DLC.exe`** 即可开始游戏。

> **⚠️ 游玩提示：**
> - 进入游戏前，请确保输入法已切换为大写或英文模式，以防按键冲突。
> - 在游戏过程中，**不要**最小化窗口或将窗口拖出屏幕外，否则可能导致画面黑屏或卡死。
> - 不要随意移动或删除 `res` 文件夹内的任何文件。

## 🔧 编译与开发

如果你想通过源码编译或二次开发：

1. 确保你的电脑已安装 **Visual Studio 2019** 或更高版本。
2. 安装 **EasyX 26.1.1** 图形库。
3. 下载本项目源码，双击打开 `.sln` 解决方案文件。
4. 将编译平台切换为 **`x86`**，点击生成即可运行。

## 🗺️ 游戏内容介绍

游戏主要分为三条独立但互相联系的主线：

- **🏛️ 总统线（发展经济）：** 体验大虾帝国的兴衰，决定国家的外交与军事。
- **🕺 虾片线（虾片打法）：** 源自 213 寝室荒诞智慧的终极展现，没有最离谱，只有更离谱。
- **🏫 校园线（弘毅班）：** 基于 2024 届灵宝一高弘毅班真实事件改编，包含远足、考试、数学补弱与那些再也回不去的日子。
